# Support

MyLocalBackup is a free personal project and comes with **no support**.

- Issues and pull requests may not be answered.
- There is no promise of fixes, updates or further releases.
- Nothing here is a promise that anything works.

Reports of bugs that lose or damage data are still welcome as issues, so that
others can see them.

## Want to improve it?

You are welcome to fork the repository and continue the work under the terms of
the [MIT License](LICENSE). Please:

- read the [Disclaimer](DISCLAIMER.md) and
  [Good to know](README.md#good-to-know) first;
- test against throwaway folders, never against real data you haven't backed up
  elsewhere (`tests/MyLocalBackup.SafetyTests` shows how);
- keep the licence and third-party notices with anything you distribute.

## If MyLocalBackup lost or damaged your files

Stop using the affected drive, and don't let any tool write to it or "repair"
it. Look for another copy first (the Recycle Bin, another backup, a cloud copy,
Windows File History). If you need data recovery, use a dedicated recovery
tool or service, working from a copy of the disk where possible.
